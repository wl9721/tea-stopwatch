Tea Stopwatch V1.6

新增：
1. 螢幕保持亮起時間改為滑桿，可選 1～10 分鐘。
2. 每次按「開始 / 重置」會重新計算保持亮起時間。
3. 計時停止時立即釋放 Wake Lock。
4. 切到其他 App / 鎖屏時釋放 Wake Lock；回前景若仍在計時則重新取得。
5. 保持亮起時間到期後，不強制鎖屏，只是交回 iPhone 原本的自動鎖定機制。

保留 V1.5：
- 00:00.00 固定兩位小數
- 提示音開關
- 自訂提示間隔
- 提示音 1～5 聲
- 音量 0～100%
- 螢幕閃爍開關
- 閃爍 1～5 次
- 測試目前提示
- 重置
- 停止 / 開始
- 背景繼續計時但不發聲、不閃爍
- 回前景不補發背景提示
- 橫直皆可
- 加大齒輪
- 設定本機保存
